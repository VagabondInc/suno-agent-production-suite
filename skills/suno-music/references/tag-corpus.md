# Square-Bracket Tag Corpus

Use the smallest set that describes the intended arrangement. Put each tag on its own line. These cues are probabilistic; reinforce essential global traits in the Style field.

## Evidence Tiers

- **Core:** widely used structural cues with comparatively strong community consensus.
- **Community-reported:** repeatedly discussed or demonstrated, but model- and genre-dependent.
- **Experimental:** compositional language packaged as a bracket cue. Treat as a testable hypothesis, not recognized syntax.

## Unorthodox Form Blueprints

Copy the architecture, then rewrite the cues for the song.

### Palindrome Form

`[Intro] → [Verse A] → [Chorus] → [Bridge] → [Chorus Reversed Energy] → [Verse A Reframed] → [Outro Mirrors Intro]`

### Escalating Refrain

`[Sparse Verse] → [Refrain] → [Denser Verse] → [Refrain with Harmony] → [Instrumental Fracture] → [Refrain in New Meter] → [Cold End]`

### Through-Composed Narrative

`[Scene 1] → [Transit Interlude] → [Scene 2] → [Memory Loop] → [Scene 3] → [Coda]`

Because `[Scene]`, `[Memory Loop]`, and similar names are experimental, pair them with concrete musical cues or use established section names with descriptive suffixes.

## Failure Recovery

- If a tag is sung aloud, simplify it to a familiar section tag and move the detailed instruction into Style.
- If a duet collapses into one voice, generate the parts separately or use distinct sections; do not promise reliable per-line speaker control.
- If a solo contains vocals, remove all lyric text until the next vocal section.
- If a transition is ignored, repeat the concept once in Style rather than stacking synonyms in Lyrics.
- If `[End]` fails, use Suno's section-replace, extend, or crop controls with explicit user authorization; no ending tag is deterministic.
